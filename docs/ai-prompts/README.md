# AI prompts

The brief (section 7) says to keep your prompts. Save them here, one file per AI session, named `NN-short-topic.md` (for example `02-sonarqube-setup.md`).

Each file holds: the date, the tool, the prompt you sent (paste it as sent) and a one-line note of what you did with the answer. Link the file from the matching row in `docs/ai-use-record.md`.

Do not edit a prompt after sending it. If you correct something, add a note below it.

`01-kickoff-prompt.md` is the first prompt (moved from the repo root).
